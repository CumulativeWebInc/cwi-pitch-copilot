🎯 CWI Pitch Copilot

Radio & Playlists dept Drafts only — never sends

The curator outreach copilot drafts playlist pitches with verified claims embedded — placement history, evidence tiers, and rights/clearance references pulled live from the CWI catalog API and the placement wall. A human approves every outbound pitch.

⛔ Exact-copy gate. Anything sent in Black's personal name, or a DM sent as Black, requires Black's explicit exact-copy approval of the final text — every draft carries this checklist. The tool drafts only; it never sends, posts, or DMs. Personal Facebook is read-only. No subscriber blasts. This is a standing hard line and it is written into the tool, not just this page.

Usage

# Draft a pitch (writes draft.md, appends a receipt line to receipts.jsonl)
node pitch-copilot.js draft \
  --to-curator "Marcus Hale" \
  --to-playlist "Underground Rap Weekly" \
  --track "Zooted Zone" \
  --note "Optional context from the department" \
  --out draft.md --log receipts.jsonl

# Check a claim before quoting it anywhere
node pitch-copilot.js check --claim "Zooted Zone holds #30 on New Rap Hits" --track "Zooted Zone"

# Probe the gate adversarially — invented placements are refused
node pitch-copilot.js adversarial "Zooted Zone is #1 on Spotify Global"

# List verified claims for a track
node pitch-copilot.js list --track "Shaka Zulu"
--fixture pins the local fixture snapshot (used by tests and examples, deterministic). Without it the tool reads the live APIs — every question gets a fresh answer.

Evidence tiers

TierMeaningExample
TIER 1 — SCAN-VERIFIEDFull playlist scans; carries position snapshot, verified_at, proof URL“Zooted Zone holds #30 of 140 on New Rap Hits (Audiartist)”
TIER 2 — DASHBOARD-VERIFIEDDistributor-dashboard facts from catalog.jsonISRC QZDA52303345
TIER 3 — PUBLIC-SOURCEThird-party sourced, not distributor-confirmed — flagged, never quoted as verifiedDeezer-sourced ISRCs

Positions are always stated as snapshots with their verification date. A submission is not a placement; a promise is not a placement. Claims that can't be resolved against verified records are refused, never guessed.

Approval workflow

  1. Draft — pitch-copilot.js draft generates the pitch from verified data + appends the mandatory HUMAN-APPROVAL checklist.
  2. Human review — a person reads every word, owns the final wording, checks claims stay within their tiers.
  3. Gate check — if the pitch goes out under Black's personal name or as a DM in his name → Black's exact-copy approval first. No exceptions.
  4. Human sends — the sender is the human of record; the tool is never the sender. Official contact: hp@cumulativeweb.com.
  5. Receipts — drafts logged to receipts.jsonl; sends logged by the human sender.

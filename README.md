# CWI Pitch Copilot 🎯

**Curator outreach copilot for the Radio & Playlists department.**
A zero-dependency Node CLI that drafts playlist pitches with **verified claims embedded** — every claim resolved against live CWI data with its evidence tier and source. The tool **drafts only; it never sends**.

**Trial owner:** `agent:CWI_Radio` (Radio & Playlists department) — 30-day trial with receipts. Trial terms, measurement, and kill rule: [`KILL-RULE-LOG.md`](KILL-RULE-LOG.md).

## How it works

1. Reads live verified data: the placement wall (`cwi-placement-wall/placements.json`) and the catalog API (`cwi-learn/catalog.json`).
2. Takes a curator + playlist + track.
3. Embeds claims with evidence tiers:
   - **TIER 1 — SCAN-VERIFIED**: full playlist scans (position snapshots, `verified_at`, proof URL)
   - **TIER 2 — DASHBOARD-VERIFIED**: distributor-dashboard facts (e.g. ISRCs)
   - **TIER 3 — PUBLIC-SOURCE**: third-party sourced, flagged as *not distributor-confirmed*, never quoted as verified
4. Appends a **mandatory HUMAN-APPROVAL checklist** — including the exact-copy gate: anything sent in Black's personal name, or as Black, needs Black's explicit exact-copy approval. Hard line.

## Usage

```bash
# Draft a pitch (drafts only — the human sends)
node pitch-copilot.js draft --to-curator "Marcus Hale" --to-playlist "Underground Rap Weekly" --track "Zooted Zone" --note "Optional context" --out draft.md --log receipts.jsonl

# Check a claim before quoting it
node pitch-copilot.js check --claim "Zooted Zone holds #30 on New Rap Hits" --track "Zooted Zone"

# Probe the gate adversarially
node pitch-copilot.js adversarial "Zooted Zone is #1 on Spotify Global"

# List verified claims for a track
node pitch-copilot.js list --track "Shaka Zulu"
```

`--fixture` uses the pinned snapshot in `fixtures/` (deterministic; used by tests and `examples/`). Without it, the tool reads the live APIs — **every question gets a fresh answer**.

## The gate

The claim gate **refuses** rather than guesses:
- Unknown track → refused
- Position mismatch vs. the verified snapshot → refused (no inflation)
- Invented placement (a submission ≠ a placement; a promise ≠ a placement) → refused
- Ambiguous claims that don't name track + playlist → refused

Receipts: `--log` appends a JSONL line per draft (timestamp, curator, playlist, track, claim IDs, draft SHA) — the trial's draft count.
